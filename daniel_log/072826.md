# Update: July 28, 2026
I've condensed July 24's and July 28's updates into a single file.

## Changed: gemini_analyze_object.py
- Reduced the temperature field from 0.5 to 0.2 to limit AI creativity when choosing labels.
- Discouraged generic object names (toy, object, ball, etc.) which were observed in previous tests.

### Suggestion: Include toy-list
- Right now, gemini_analyze_object.py does not have access to toy-list (unlik**e the spatial prompt files).
- Including this list tells the AI to select from only the toys in the list (instead of creating new answers like stress ball).

### Suggestion: Make questions more specific
- This may not be tied to the prompt file, but some questions can be answered by multiple objects (Show me something you squeeze to make a drink!)
- Consider classifying by color and shape instead.

## Changed: gemini_validate_spatial.py
- Prepositions: on, off, next to, under, above, away from
- Instead of telling the AI to "pick one" of these, the file will only prompt the AI to check against the desired condition. This will prevent confusion between similar prepositions (Ex. above and away from).
- Ex. If the robot expects above, the robot won't think "Is it above or on or below or ...etc" but rather "Is it above or not above" (in a binary yes/no format)

## Changed: gemini_validate_spatial_video.py
- Prepositions: in, out, behind, in front of
- Similar changes as above

### Suggestion: Delete actual_relation key from JSON
Since I don't know every file the JSON is being used in, I'll leave the deletion to you to avoid causing bugs. I've deprecated actual_relation for now because I am not using it.
